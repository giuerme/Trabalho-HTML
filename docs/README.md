Documentação técnica — Movimento Sem Fome

> **Disciplina:** Desenvolvimento Front-End para Web · **Instituição:** UNICID · **Entrega:** 2ª entrega do projeto de site (AV A1) · **Referência documental:** 08/11/2026.

Esta pasta reúne os materiais solicitados pelo roteiro e pela rubrica da segunda entrega. O **Movimento Sem Fome** é um projeto acadêmico demonstrativo de divulgação de iniciativas ligadas à segurança alimentar, ao apoio às famílias e à redução do desperdício. A documentação não constitui comprovação de doações, parcerias ou ações sociais efetivamente realizadas.

**Repositório:** https://github.com/giuerme/Trabalho-HTML  
**Endereço informado do site:** https://trabalho-html-self.vercel.app/
