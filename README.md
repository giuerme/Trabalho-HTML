# Movimento Sem Fome (MSF)

O **Movimento Sem Fome (MSF)** é um projeto de site institucional que apresenta uma plataforma voltada à conexão entre estabelecimentos com excedentes de alimentos e instituições que precisam desses recursos.

O projeto busca contribuir para a **redução do desperdício de alimentos** e para o **impacto social**, apresentando a proposta, suas funcionalidades e seus possíveis resultados.

## 🎯 Objetivo

Apresentar o conceito e o funcionamento da plataforma MSF por meio de um site desenvolvido em **HTML5, CSS3 e JavaScript**.

## 📄 Páginas

O site é será por 10 páginas:

- `index.html` — Página inicial ✅
- `sobre.html` — História, missão, visão, valores e equipe
- `projetos.html` — Funcionalidades da plataforma
- `impacto.html` — Indicadores e impacto do projeto
- `acessibilidade.html` — Recursos de acessibilidade
- `galeria.html` — Galeria de imagens
- `midia.html` — Vídeo, áudio e mapa
- `noticias.html` — Notícias e artigos
- `contato.html` — Formulário de contato
- `orcamento_hospedagem.html` — Comparativo de hospedagem e domínio

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## ♿ Acessibilidade

O projeto busca garantir uma navegação acessível, utilizando:

- Textos alternativos em imagens;
- Navegação por teclado;
- Contraste adequado;
- Estrutura semântica;
- Compatibilidade com leitores de tela.
